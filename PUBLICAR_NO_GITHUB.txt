MCO GAMES — Correção das logos no GitHub Pages (v0.7.9)

IMPORTANTE: O ZIP contém os arquivos na RAIZ, sem pastas internas.

1. Extraia o ZIP no seu computador.
2. No GitHub, repositório mcogames/tutorial-ps5-, branch main, clique Add file > Upload files.
3. Arraste TODOS os 4 arquivos DIRETAMENTE para a raiz do repositório (na mesma página do index.html):
   index.html
   logo-mco-principal.png
   logo-mco-simbolo.png
   favicon-mco.png
4. Confirme o commit.
5. Em Code, confira que os três arquivos PNG aparecem junto de index.html.
6. Em Actions, aguarde a conclusão bem-sucedida de pages build and deployment.
7. Abra https://mcogames.github.io/tutorial-ps5-/?v=0.7.9 e recarregue com Ctrl+Shift+R.
8. Para testar cada imagem individualmente, abra:
   https://mcogames.github.io/tutorial-ps5-/logo-mco-principal.png
   https://mcogames.github.io/tutorial-ps5-/logo-mco-simbolo.png

Causa provável do problema anterior: ausência das imagens publicadas no GitHub ou versão diferente da servida no Pages.
O HTML desta versão usa caminhos relativos simples (./nome.png), sem dependência de data URIs extensas nem pasta assets.
Aproveitamos o HTML da v0.7.8 e preservamos os roteiros Primária, Secundária e Cadeado.
